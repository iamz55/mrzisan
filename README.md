# Z. — Social Links Website

A static, responsive social-links website designed from the supplied reference.

## Files

```text
z-social-links/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── profile.jpg
    └── mountain.jpg
```

## Customize your site

### 1. Profile photo
Replace:

`assets/profile.jpg`

with your own image. Keep the filename `profile.jpg`.

### 2. Mountain image
Replace:

`assets/mountain.jpg`

with your own mountain/background image. Keep the filename `mountain.jpg`.

### 3. Social links
Open `index.html` and change the URLs in the six `<a>` tags:

- Instagram
- YouTube
- X
- Discord
- Telegram
- GitHub

### 4. Text
You can change `Z`, the description, "EST. 2025", and other text directly in `index.html`.

## GitHub Pages

1. Create a GitHub repository.
2. Upload everything inside this folder.
3. Make sure `index.html` is in the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
6. Save.
7. GitHub will give you your Pages URL.

For a username site, the repository should normally be named:

`YOUR_USERNAME.github.io`

Then your website will be available at:

`https://YOUR_USERNAME.github.io/`

No server, Node.js, npm, or database is required.
